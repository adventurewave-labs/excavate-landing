What it does

Resurrection

Dead website from the Wayback Machine → modern static site on disk. Inventory → pull → clean → check → scan → report → export. Resumable at every stage, rate-respecting by design.

Nothing faked, ever

A missing file is listed as missing. Every rewrite is logged in REWRITES.md, every fetch digest-verified, every failure classified per-row. The verification report is the chain of custody.

Publish gate

Before anything ships: a scan for credentials and bulk personal data. Any unreviewed finding exits 1. The archive is honest even about what shouldn't be published.

Live-validated, not mocked

Until November 2026 every test used a mocked archive. Then the first complete dig ran against the real Wayback Machine — 19 pipeline cycles over two days, zero crashes, through two live archive-degradation windows. Full per-cycle log: docs/live-dig-2026-11-16.md.

The pipeline

INVENTORY

CDX survey — paginated, never collapsed or filtered. Every raw row kept.

PULL

≤30 req/min, id_→im_ fallback, digest-verified, resumable.

CLEAN

De-Waybacked, page-relative links, charset-faithful, twins where archives allow.

CHECK

Walks every link: recovered / archived-not-recovered / never archived / orphans.

DISCOVER

Exact-URL lookups for linked-but-missing files — dead ends confirmed, not guessed.

SCAN

Publish gate: credentials & bulk personal data. Exit 1 on unreviewed findings.

REPORT

VERIFICATION-REPORT.md — counts, rewrites, gaps, chain of custody.

EXPORT

BagIt (RFC 8493) bag: site + raw captures + the full paper trail.

Commands

excavate run <domain>the whole pipeline; --limit N instalments, --strict
excavate inventory <domain>CDX survey; --match prefix|host|domain, --from/--to, --at DATE
excavate pullrate-limited fetches, resumable; --dry-run forecasts cost
excavate cleanraw/ → site/, de-Waybacked, charset-faithful, twin swaps
excavate checkwalk the site's links → crawl.json
excavate discoverexact-URL CDX lookups for linked-but-missing files
excavate scanpublish gate; --allow FP --reason to clear a false positive
excavate reportverification report — counts, integrity, custody
excavate exportBagIt bag; --zip, --verify BAG checks any bag
excavate statuswhere the dig stands, what to run next — no network
